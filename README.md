Neon Coast Cover Studio: an offline web app that turns your photos and a caption into GTA-style multi-panel cover art — six layouts, five gradient-map grades, Anton + Pacifico lettering, halftone title block, badge ribbon, grain and vignette — and exports it as a PNG in 1080 x 1080, 1080 x 1350, 1920 x 1080 and 1080 x 1920. Everything runs in a desktop browser from static files; photos never leave the machine. All art, lettering and fonts are original or SIL OFL licensed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Pick photos (or drop them on the cover), choose a layout and a grade, write the caption, and export.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
